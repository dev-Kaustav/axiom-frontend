- Python str(Decimal) can produce exponent notation such as "1E-7"; decimal strings must be passed through verbatim, never normalised.
- CORS/same-origin deployment forwarding for the deployed site belongs to AXF-06 (OPS-01). Backend code is not edited in this phase.
